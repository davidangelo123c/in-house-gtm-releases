# In-House GTM releases

The release notice for In-House GTM. Each client's Claude reads `release.json` here to see the latest version, what's new, and where to download it.

- `release.json`: latest version, release notes, full changelog, download link and checksum.
- `CHANGELOG.md`: every version, newest first.

The app files themselves are kept in Google Drive. No client data is stored here.
